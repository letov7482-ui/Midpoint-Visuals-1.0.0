# Midpoint Visuals

Современный визуальный клиент для Minecraft Fabric 1.21.4.

## Модули
- Emotes (сидеть, вращение 360°)
- Shift Tap
- Healing Helper
- Cooldowns
- Item Scroller
- Item Swap
- Elytra Swap
- Totem Tracker
- Free Look
- Aspect Ratio
- Block Overlay
- Fullbright
- Hitbox Customizer
- Particles
- Target ESP
- World Particles
- Nimb
- Hud
- Potions
- Target Hud
- Watermark

## Сборка
`./gradlew build`
